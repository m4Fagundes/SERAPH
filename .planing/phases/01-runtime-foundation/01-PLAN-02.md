<objective>
Create `requirements-macos.txt` (macOS ARM64, MPS-capable) and `requirements-windows.txt` (Windows CUDA, identical to the current `requirements.txt` content plus the three missing deps).

Purpose: The current `requirements.txt` hardcodes `torch==2.6.0+cu124` from a CUDA-only index — this fails on macOS entirely. DEP-01 requires `pip install` to succeed on macOS ARM64. DEP-02 requires platform-split torch installation. DEP-03 requires the three missing runtime deps. The split-file approach avoids the pip bug (issue #13637) where `--extra-index-url` combined with environment markers causes markers to be silently ignored.

Output: Two new files. `requirements.txt` is left in place (pointing to Windows/CUDA behavior for the existing broken CI) so no CI references break before Phase 3.
</objective>
