**Step 3 — Activate venv and verify dependencies:**

```bash
cd /path/to/grid-image-analyzer   # repo root
pyinstaller --clean --noconfirm docs/build/main_release.spec 2>&1 | tee /tmp/pyinstaller_build.log
```
Expected: Build completes with `Building BUNDLE GridAnalyzer.app completed successfully.` at the end.
If the build fails with `ModuleNotFoundError` for pyvips or openslide: check that pyvips-binary and openslide-bin are installed and that requirements-macos.txt was installed correctly.

```bash
ls dist/GridAnalyzer.app/Contents/MacOS/

find dist/GridAnalyzer.app -name "libopenslide*.dylib" 2>/dev/null | head -5
```
Expected:
- `dist/GridAnalyzer.app/Contents/MacOS/GridAnalyzer` exists (the main executable)
- At least one `libvips*.dylib` file is found inside the bundle
- At least one `libopenslide*.dylib` file is found inside the bundle

If either dylib is NOT found inside the bundle: the runtime hook + spec fixes did not work correctly. Check /tmp/pyinstaller_build.log for warnings about missing modules pyvips_binary or openslide_bin.

<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| Unsigned .app + quarantine | App is unsigned; macOS Gatekeeper blocks it; xattr -d is the documented workaround |
| sys._MEIPASS directory | PyInstaller extraction dir; world-readable temp space; sensitive model weights are not secrets but are bundled here |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-02-03 | Spoofing | Unsigned .app — no code signature to verify publisher identity | accept | No Apple Developer account; colleagues explicitly use xattr -d as documented workaround; out of scope per project decisions |
| T-02-04 | Tampering | Cellpose model weights bundled in dist/.app — could be replaced by adversary with write access to dist/ | accept | Cellpose weights are public pre-trained models with no PII; replacing them would produce wrong segmentation, not a security breach |
</threat_model>
