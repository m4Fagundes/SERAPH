<!-- Build machine requirements and create-dmg tool reference. -->

Tool: create-dmg (Homebrew)
Install: brew install create-dmg
GitHub: https://github.com/create-dmg/create-dmg

Minimum create-dmg invocation:
```bash
create-dmg \
  --volname "GridAnalyzer" \
  --window-size 540 380 \
  --app-drop-link 380 170 \
  --icon "GridAnalyzer.app" 160 170 \
  "dist/GridAnalyzer.dmg" \
  "dist/GridAnalyzer.app"
```

Alternative (hdiutil only, no Homebrew dependency):
```bash
hdiutil create -volname "GridAnalyzer" -srcfolder dist/GridAnalyzer.app \
  -ov -format UDZO "dist/GridAnalyzer.dmg"
```

The hdiutil fallback does NOT include a drag-to-Applications symlink, so create-dmg is preferred.
The create-dmg tool handles the Applications symlink automatically.

Version pin in CI (Phase 3): no pin needed for Phase 2; latest create-dmg is fine.
</interfaces>

Create scripts/create_dmg.sh with the following content (make it executable):

```bash
#!/usr/bin/env bash
# scripts/create_dmg.sh — Build a distributable .dmg from dist/GridAnalyzer.app
#
# Requirements:
#   - macOS ARM64
#   - brew install create-dmg
#   - dist/GridAnalyzer.app must already exist (run PyInstaller first)
#
# Usage:
#   bash scripts/create_dmg.sh
#
# Output:
#   dist/GridAnalyzer.dmg

set -euo pipefail

REPO_ROOT="$(cd "$(dirname "${BASH_SOURCE[0]}")/.." && pwd)"
APP_PATH="$REPO_ROOT/dist/GridAnalyzer.app"
DMG_PATH="$REPO_ROOT/dist/GridAnalyzer.dmg"
VOL_NAME="GridAnalyzer"

echo "==> Checking prerequisites..."

if [[ ! -d "$APP_PATH" ]]; then
  echo "ERROR: $APP_PATH does not exist. Run PyInstaller first:"
  echo "  pyinstaller --clean --noconfirm docs/build/main_release.spec"
  exit 1
fi

if ! command -v create-dmg &>/dev/null; then
  echo "ERROR: create-dmg not found. Install with: brew install create-dmg"
  exit 1
fi

echo "==> Removing old .dmg if present..."
rm -f "$DMG_PATH"

echo "==> Creating $DMG_PATH from $APP_PATH ..."
create-dmg \
  --volname "$VOL_NAME" \
  --window-size 540 380 \
  --background-color "#FFFFFF" \
  --icon-size 128 \
  --icon "GridAnalyzer.app" 160 170 \
  --app-drop-link 380 170 \
  --hide-extension "GridAnalyzer.app" \
  "$DMG_PATH" \
  "$APP_PATH"

echo ""
echo "==> Done. Disk image created at: $DMG_PATH"
du -sh "$DMG_PATH"
```

After creating the file, make it executable:
On macOS/Linux: `chmod +x scripts/create_dmg.sh`
On Windows (where this task may be authored): set the executable bit via git:
`git update-index --chmod=+x scripts/create_dmg.sh`
