<objective>
Rewrite `.github/workflows/build-macos.yml` to fix all four known breakage points so that
a `macos-14` (Apple Silicon) GitHub Actions runner can build and upload `GridAnalyzer.app`
and `GridAnalyzer.dmg`.

The current workflow has four fatal problems:
1. Builds on both `macos-13` (Intel) and `macos-14` (ARM64) — we want ARM64-only.
2. Installs `requirements.txt` (CUDA torch) — fails on macOS entirely.
3. Runs `pyinstaller ... main_release.spec` — file does not exist at repo root; spec lives at `docs/build/main_release.spec`.
4. Missing `brew install libvips openslide` — pyvips and OpenSlide dylibs are needed at bundle time even though `pyvips-binary` and `openslide-bin` provide them for local dev; on a clean CI runner they must be Homebrew-installed.

Additional cleanups: remove deferred code-signing step, update stale action versions,
fix pip cache key to hash `requirements-macos.txt`, fix `create-dmg` (remove non-existent
`--volicon app.icns`), update path triggers to reflect platform-split requirements files.

Output: `.github/workflows/build-macos.yml` replaced with a correct, working version.
</objective>

    ```yaml
    name: Build macOS App

    on:
      push:
        branches: [ main, develop ]
        tags:
          - 'v*'
        paths:
          - 'app/**'
          - 'main.py'
          - 'requirements-macos.txt'
          - 'docs/build/main_release.spec'
          - 'hooks/rthook_cellpose.py'
          - 'hooks/rthook_openslide.py'
          - '.github/workflows/build-macos.yml'
      workflow_dispatch:

    permissions:
      contents: write

    jobs:
      build-macos:
        runs-on: macos-14

        steps:
          - name: Checkout code
            uses: actions/checkout@v4

          - name: Set up Python 3.12
            uses: actions/setup-python@v5
            with:
              python-version: '3.12'

          - name: Cache pip dependencies
            uses: actions/cache@v4
            with:
              path: ~/.cache/pip
              key: ${{ runner.os }}-pip-${{ hashFiles('requirements-macos.txt') }}
              restore-keys: |
                ${{ runner.os }}-pip-

          - name: Install Homebrew dependencies
            run: |
              brew install libvips openslide

          - name: Install Python dependencies
            run: |
              python -m pip install --upgrade pip
              pip install -r requirements-macos.txt
              pip install pyinstaller

          - name: Build with PyInstaller
            run: |
              pyinstaller --clean --noconfirm docs/build/main_release.spec

          - name: Create DMG
            run: |
              brew install create-dmg || true
              create-dmg \
                --volname "GridAnalyzer" \
                --window-pos 200 120 \
                --window-size 600 400 \
                --icon-size 100 \
                --icon "GridAnalyzer.app" 200 190 \
                --hide-extension "GridAnalyzer.app" \
                --app-drop-link 400 190 \
                "dist/GridAnalyzer.dmg" \
                "dist/GridAnalyzer.app"
            continue-on-error: true

          - name: Upload .app artifact
            uses: actions/upload-artifact@v4
            with:
              name: GridAnalyzer-arm64.app
              path: dist/GridAnalyzer.app
              retention-days: 30

          - name: Upload .dmg artifact
            uses: actions/upload-artifact@v4
            with:
              name: GridAnalyzer-arm64.dmg
              path: dist/GridAnalyzer.dmg
              retention-days: 30
            continue-on-error: true

          - name: Create Release
            if: startsWith(github.ref, 'refs/tags/')
            uses: softprops/action-gh-release@v2
            with:
              files: |
                dist/GridAnalyzer.dmg
                dist/GridAnalyzer.app
            env:
              GITHUB_TOKEN: ${{ secrets.GITHUB_TOKEN }}
    ```
