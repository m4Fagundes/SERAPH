<objective>
Trigger the fixed `build-macos.yml` workflow via `workflow_dispatch` and verify that
the `macos-14` runner completes successfully and produces downloadable artifacts
(`GridAnalyzer-arm64.app` and `GridAnalyzer-arm64.dmg`).

This is a manual verification checkpoint. The executor pushes the Plan 01 commit to
`origin/main` (or creates a PR), monitors the workflow run until it completes, and
confirms artifact availability. No code changes are made in this plan.

Success = CI-03 satisfied: `.app` and `.dmg` artifacts available for download from
the workflow run summary page.
</objective>

<task id="T1" type="execute">
  <title>Push the fixed workflow to GitHub and trigger the run</title>
  <read_first>
    - `.github/workflows/build-macos.yml` — confirm it contains `runs-on: macos-14` and `docs/build/main_release.spec` before pushing.
    - `git log --oneline -3` — confirm Plan 01 commit is present and not yet pushed.
  </read_first>
  <action>
    1. Confirm the Plan 01 commit is present:
       ```
       git log --oneline -3
       ```
       Expect to see the commit `fix(ci): rewrite build-macos.yml — ARM64-only, fix spec path, add Homebrew deps (CI-01, CI-02, CI-04)`.

    2. Push to origin:
       ```
       git push origin main
       ```
       This will trigger `build-macos.yml` because `.github/workflows/build-macos.yml`
       is in the `paths` trigger list.

    3. Alternatively, if you prefer not to push directly to `main`, create a PR branch:
       ```
       git checkout -b fix/ci-macos-arm64
       git push -u origin fix/ci-macos-arm64
       ```
       Then open a PR; the `workflow_dispatch` trigger can also be used from
       GitHub UI → Actions → Build macOS App → Run workflow → Branch: fix/ci-macos-arm64.

    **Note:** The build will take approximately 20-40 minutes on `macos-14` (PyInstaller
    collecting torch + cellpose is the long step). Do not cancel early.
  </action>
  <acceptance_criteria>
    - `git log --oneline -3` shows the Plan 01 fix commit
    - `git push` exits 0 (or PR is opened)
    - GitHub Actions → Build macOS App shows a new run in progress or queued for `macos-14`
  </acceptance_criteria>
</task>

<task id="T2" type="execute">
  <title>Monitor the workflow run and verify artifacts</title>
  <read_first>
    - GitHub Actions run URL (from previous task output or `gh run list --workflow=build-macos.yml --limit=1`)
    - The workflow run log — focus on "Install Homebrew dependencies", "Build with PyInstaller", "Create DMG", and "Upload .app artifact" steps.
  </read_first>
  <action>
    Monitor the workflow run using the GitHub CLI:

    ```bash
    # Watch the most recent build-macos run until it completes
    gh run watch $(gh run list --workflow=build-macos.yml --limit=1 --json databaseId --jq '.[0].databaseId')
    ```

    Once complete, check the outcome:

    ```bash
    # List the run status
    gh run list --workflow=build-macos.yml --limit=1

    # List artifacts from the run
    gh run download --dir /tmp/ci-artifacts $(gh run list --workflow=build-macos.yml --limit=1 --json databaseId --jq '.[0].databaseId') --name GridAnalyzer-arm64.app 2>&1
    ```

    **If the workflow PASSES:**
    - Confirm `GridAnalyzer-arm64.app` artifact is present in the run summary.
    - Confirm `GridAnalyzer-arm64.dmg` artifact is present (or note if `Create DMG` step
      used `continue-on-error` — that is acceptable for Phase 3 as long as .app is present).
    - Record the run URL and artifact sizes.

    **If the workflow FAILS, diagnose by step:**

    | Failing Step | Likely Cause | Fix |
    |---|---|---|
    | Install Homebrew deps | brew formula name change | Try `brew install vips` instead of `libvips` |
    | Install Python deps | pyvips-binary wheel mismatch on macOS-14 | Check `pip install pyvips-binary` error message; may need `pyvips[binary]` extra instead |
    | Build with PyInstaller | Missing hidden import or hook error | Read PyInstaller output; add missing import to spec's `hiddenimports` |
    | Create DMG | create-dmg failure (non-fatal) | Acceptable if `.app` artifact uploaded; CI-03 satisfied by `.app` alone |
    | Upload artifact | Path `dist/GridAnalyzer.app` not found | PyInstaller step must have failed; check that step's logs |

    Record the diagnosis and resolution in the summary.
  </action>
  <acceptance_criteria>
    - `gh run list --workflow=build-macos.yml --limit=1` shows `completed` with conclusion `success`
    - GitHub Actions run summary page lists artifact `GridAnalyzer-arm64.app` with size > 0 bytes
    - `gh run list --workflow=build-macos.yml --limit=1 --json conclusion --jq '.[0].conclusion'` outputs `"success"`
  </acceptance_criteria>
</task>
