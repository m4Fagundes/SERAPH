## Data Flow

1. **Image Loading** → User adds image → `ImageSession` opens via Pillow, generates LOD cache
2. **Rendering** → `redraw()` computes viewport, crops visible region, resizes to canvas, draws grid + selection overlay
3. **Interaction** → Pan/zoom update `camera_x`/`camera_y`/`zoom_level` on session → triggers `redraw()`
4. **Selection** → Right-click computes grid cell coords → toggles in `selected_cells` set
5. **Export** → Iterates selected (or all) cells → crops from `original_image` → saves with format-specific options
6. **Persistence** → `_write_project_file` serializes all sessions to JSON `.lab` file → autosave on 2s debounce
